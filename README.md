# 📚 Atividades de Lógica de Programação

Repositório com atividades e exercícios desenvolvidos durante a disciplina de **Lógica de Programação** do curso de Análise e Desenvolvimento de Sistemas.

## 💻 Tecnologia

- Dart

## 📖 Conteúdos praticados

- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais

- Funções
- Entrada e saída de dados

## 🎓 Contexto

Atividades desenvolvidas durante o **2º semestre de ADS**, com o objetivo de praticar os fundamentos da programação utilizando Dart.
